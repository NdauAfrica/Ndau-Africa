What we build

AYLI — multimodal evidence engine for informal and semi-formal work

Ndau Africa builds AYLI, a system that turns ordinary job-site photos and videos — plus work context and optional client confirmation — into structured Economic Actor Records (EARs).

An EAR records what was observed, what activity that supports, which capability hypotheses are reasonable, how confident the system is, and where a human should review.

AYLI is

Evidence infrastructure · human-reviewable · provisional · auditable · built for real sites

AYLI is not

A certificate issuer · worker ranking engine · job board · automated credit decision system

Methodology

Trust over volume

1. Evidence-anchored observation

The model must point to visible actions and tools before any capability hypothesis.

2. Unsupported-claim detection

A second pass challenges statements that go beyond the footage.

3. Human-in-the-loop

HITL flags escalate weak or mixed evidence. AI accelerates review; it does not replace judgement.

4. Data governance

Consent at capture. Pilot records are provisional. Not for automated underwriting without institutional safeguards.
